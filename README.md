# VALMORA &bull; Grand Tourer

A bespoke digital showroom experience for the **VALMORA Grand Tourer** — handcrafted in metallic oxblood lacquer with an all-aluminium body, 4.7L quad-cam naturally aspirated V8, and 72-spoke Borrani wire wheels.

🔗 **Live Deployment:** [https://aritakulaganeshnicedigital-ops.github.io/Valmora-Cars/](https://aritakulaganeshnicedigital-ops.github.io/Valmora-Cars/)

---

## ✨ Features

- **Cinematic Dust Cover Unveil:**
  - Sticky viewport scroll lock (`420vh`) keeping the vehicle perfectly framed in the viewport.
  - Realistic scroll-linked cloth physics peeling away the tailored dust sheet.
  - Studio cinematic spotlight sweep and anamorphic optical flares.
  - Unobstructed reveal allowing full visibility of the car coachwork.

- **Interactive 360° Turntable & Close-Up Camera:**
  - Full 360° interactive rotation with touch/drag support and auto-spin modes.
  - **Dynamic Close-Up Camera Dolly:** Clicking exterior view selectors (*Headlights*, *Engine & Hood*, *Wire Wheels*, *Rear Fastback*, *Coachwork*) smoothly animates the camera into tight macro focus on that exact component.
  - **Macro Component Modal:** Displays high-resolution photography and engineering specifications for each handcrafted part.
  - **On-Stage HUD:** Live camera target reticle and one-click reset to full vehicle view.

- **Luxury Web Audio Engine:**
  - Real-time synthesized low-frequency V8 ambient rumble and studio resonance via Web Audio API.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Semantic structure, CSS custom properties, responsive flex/grid, hardware-accelerated transforms, and backdrop filters.
- **Vanilla JavaScript (ES6+):** Zero external libraries; lightweight LERP scroll interpolation, turntable rotation math, and camera matrix transitions.
- **Web Audio API:** Real-time dual-oscillator acoustic rumble generator.
